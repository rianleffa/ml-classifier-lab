# Capturas reais da aplicação

Salve aqui as capturas feitas com a aplicação em execução. Não há imagens de demonstração neste diretório.

Sugestões para a entrega:

1. Visão geral com os dados carregados.
2. Configuração do treinamento antes de executar.
3. Tela de avaliação após uma execução real, incluindo as métricas.
4. Matriz de confusão e gráfico da validação cruzada.
5. Análise crítica e distribuição das classes.
6. Código Python e histórico/exportação do relatório.

Registre a captura diretamente da janela do navegador e mantenha visível o contexto da aplicação. Anote no nome ou em um pequeno índice a data, a página e o identificador da execução para relacionar as imagens aos arquivos em `results/`.
